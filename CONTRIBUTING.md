# Contributing

This is a portfolio / product prototype. Small, focused pull requests are welcome.

1. Fork the repo and create a branch from `main`
2. Keep secrets out of Git — never commit `backend/.env`
3. Match existing naming in `backend/app` and `frontend/src`
4. Open a pull request that says what changed and how you tested it (local health check, register, generate or clone a trip)

For architecture and API contracts see [ARCHITECTURE.md](ARCHITECTURE.md) and [API.md](API.md).
